# Real-Time Application 1: Smart Agriculture Sensor Monitor

Problem Scenario
A smart farm collects data from soil-moisture, temperature, and humidity sensors. Every sensor is
represented as an object with a unique ID, a current reading, and a time stamp. The monitoring
software must update readings and display sensor status.
OOP Concepts Used
 •   Class and object
 •   Encapsulation through private data members
 •   Parameterized constructor
 •   Member functions
 •   Vector of objects
 •   Range-based loop
